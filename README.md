## Product & Market Intelligence Platform

A GenAI-powered application that analyzes product launches, market sentiment, and public performance signals using large language models and live web data.

The system uses LLMs to reason over real-time information fetched from the web and convert unstructured data into structured competitive insights.

It enables users to input a company name and receive insights on product positioning, launch strengths and weaknesses, customer sentiment, and market traction.

Firecrawl is used to fetch up-to-date web content from news, blogs, reviews, and forums, ensuring analyses reflect current market signals.

The application is built with Streamlit for an interactive UI and supports OpenRouter-based LLM inference.

Designed to demonstrate applied GenAI, market analysis, and real-world decision intelligence use cases.
